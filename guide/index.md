# 介绍

![Vivian](/imgs/vivian.png)
Vivian 是一个采用类液态玻璃设计风格的 VitePress 主题，为了兼容性其实算是模糊和高光为重。

基于默认主题魔改，基本上使用 Mimo V2.5 Pro 实现 ~~-15 CNY~~😭

名字来源于《绝区零》角色薇薇安（我甚至没有薇薇安😡）

## 特性

- 类液态玻璃设计风格
- 支持跟随系统的深浅色模式
- Twikoo 评论系统集成
- 响应式设计
- 带点动画
